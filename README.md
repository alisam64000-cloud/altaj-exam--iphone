# AL-TAJ Exam Studio — iPhone and iPad
This repository contains **only the public app shell** (HTML, CSS, JavaScript). No books, quiz answers, medical images, progress, or user files are included.

Visit [AL-TAJ Exam Studio](https://alisam64000-cloud.github.io/altaj-exam--iphone/) on **Safari** and use Share > Add to Home Screen. Import your authorized JSON book files using the Books section. The app caches its shell offline via Service Worker and saves study data locally to the browser storage. Do not clear website storage without exporting your data.

The private development repository remains private. This public deployment exposes its web-app UI/source to readers, but not the iOS native Xcode or Android projects.

Deployment requires enabling GitHub Pages > Source: GitHub Actions in this repo's Settings > Pages (if not already enabled).
